Running header

A rule from the left edge, the current topic's name, and a mark on the right. The name follows whichever topic the page falls under, and a topic's opening page carries no header since its title is already there. The band matches the footer's height.

Footer

The header sits inside the top margin. The footer bleeds to the full page width, flush with the bottom edge. Both repeat on every content sheet, and PNG keeps a transparent background.

The built-in mark takes the header's own colour so it works on any paper. An uploaded one keeps its own colours.
